**统一目标与完成定义**

用户能够在手机与桌面之间连续开发同一 Android 项目，理解当前进度，控制执行过程，并得到与本轮代码版本对应、验证状态明确的 APK。

代表性完整流程是：选择项目或 Recipe → 识别工程能力 → 必要时选择方案 → 读取与修改 → 查看差异 → 构建/测试 → 安装 → 收集运行反馈。桌面编辑器、Agent、手机必须共享项目身份、会话事实和文件版本。

完成不能仅由模型的一句“已完成”决定。交付结果必须关联 project、conversation、task、turn、代码 revision/快照及产物；分别标记已修改、已构建、已测试、已安装、已打开目标页面、已执行视觉检查。没有执行的验证标为未验证，代码在构建后变化则标记 APK 已过期。
