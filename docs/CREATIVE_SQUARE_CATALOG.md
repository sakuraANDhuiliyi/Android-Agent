# 创意广场样式目录

当前收录 **500 个 UI 示例**：原有 6 个组件 + 494 个风格与布局组合。新增内容分为 **26 个视觉系列、48 套布局实现**。上限为 500，目录和生成器都拒绝超额收录。

## 使用

- App 导航中的「创意」进入；游客也可离线浏览。
- 搜索支持中文、英文风格 ID、布局名称和多个空格分隔关键词；分类与风格筛选可组合。
- 点击缩略图或卡片正文打开详情。缩略图展示真实布局，详情可操作按钮、开关、滑杆和输入框。
- 「复制代码」包含 import、所需辅助函数、样式参数和独立入口；每份配方使用唯一的辅助类型名，可放入同一个包；「应用到项目」沿用已有项目选择及 Agent 流程。
- 详情中的参考链接交由浏览器打开。参考的是公开设计语言，预览与源码由本项目原创，不打包第三方图片或源码。
- 天气、交易、路线、消息等内容是示例数据；计时器和本地控件可实际交互，涉及业务服务的按钮只演示状态。

## 维护与验证

- 数据源：`tools/creative/catalog.json`，明确列出 26 系列的编辑选择，不自动生成全部风格 × 布局的排列。
- 原生预览：`creative/styles/StyleFoundation.kt` 和 `StyleLayouts.kt`。
- 生成器：`scripts/generate_creative_catalog.py`；生成 Kotlin 元数据、布局分发和复制源码。复制源码取自同一份原生预览实现，避免两份代码漂移。
- 源码按需生成；列表只组合可见卡片。500 个长源码字符串不会在目录初始化时全部分配。
- 修改数据或布局后执行：

```bash
python3 scripts/generate_creative_catalog.py
python3 scripts/generate_creative_catalog.py --check
cd android-app
./gradlew testDebugUnitTest assembleDebug --offline
```

可选：编译实际复制出的代码，覆盖全部布局、全部风格及原有六个示例。先选择一个全新的临时输出目录：

```bash
cd android-app
./gradlew testDebugUnitTest --tests '*CreativeCatalogTest' \
  -I ../tools/creative/validate-recipes.init.gradle \
  -PcreativeExportDir=/tmp/creative-recipes
./gradlew compileDebugKotlin \
  -I ../tools/creative/validate-recipes.init.gradle \
  -PcreativeValidationSources=/tmp/creative-recipes
# 验证结束后正常构建，APK 不包含临时验证代码。
./gradlew assembleDebug
```

样式自身保留固定色板，App 外层遵循系统深浅色；玻璃感采用渐变光斑和透明叠层，不依赖高版本背景模糊 API。
