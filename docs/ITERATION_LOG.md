## 双端动态任务表情

日期：2026-10-09。状态：实现、独立审查与完整验收已完成。

Android 聊天标题栏和桌面两处助手入口接入离线 SVG 表情，映射实际任务状态。修复未知状态回退、后台与被遮挡面板仍播放动画、页面恢复及系统减少动画偏好等边界。上游的球形角色仍限个人技术学习研究，保留全部许可证，不能用于商业产品。

验收范围：32 种原始表情动态渲染、任务状态联动、重复状态稳定、前台动画、后台暂停/恢复、DOM 显隐、面板聚焦、减少动画、页面缓存恢复、Android 生命周期和离线本地资源。增加发布门禁中的表情专项、资源同步检查、后端 E2E、真实 Electron 场景和 Android lint；同轮更新 `brace-expansion` 5.0.9 → 5.0.12，修复依赖审计发现的递归与扩展拒绝服务问题。

加强测试时发现暂停恢复会重复追加原始指令，并从头使用响应编号，事件去重掩盖了实际命令重跑。现按 turn 身份恢复提示、响应编号与成功编辑证据；回归测试直接核对实际执行日志由 `1,2,1,2,3` 修复为 `1,2,3`，另覆盖 OpenAI/Anthropic 协议和同文新一轮输入。修正 Electron/E2E 测试使用隔离账号、数据与本地模型桩，并检查真实工具结果；修复远程更新中导致 Android lint 失败的越界布局宽度。

测试环境：Python 3.12.14、Node 24.14.0、Android Studio JBR 17、仓库现有 Android SDK。临时 Python 环境与日志位于忽略目录 `.artifacts/`，不上传凭据、数据库或本地草稿。

最终结果：默认统一发布门禁 **18/18 全通过，无跳过项**，报告 `.artifacts/iteration-001/release.json`。其中后端 566 项测试及 23 项子测试、15 个完整 E2E 场景通过；Android 174 项 JVM 测试、Debug 构建与 lint 通过（0 错误、344 条警告）；桌面单元、表情、Studio、创意接口、截图和两套 Electron 实测通过；npm audit 无漏洞。模拟器另行验证播放、关闭动画、后台静止、返回恢复和退出销毁，证据位于 `.artifacts/iteration-001/android-motion-results.json`。源文件校验和、双端资源同步、暂存区差异格式与敏感信息扫描通过。

下一轮已确认的恢复缺口：worker 每次续跑重置本轮快照、构建与编辑事实，暂停时提前写入终态快照；会影响跨暂停的变更审查与最终验证记录。已消费的 steer 也没有写入规范历史，尚未覆盖真实引导消息的暂停恢复。本轮解决重复执行，不据此宣称恢复链路已全部完成。下一轮先修复这些事实恢复和检查点边界，再补双端恢复入口。

## 本任务最近一次验证

日期：2026-10-10。状态：实现、交叉审查和完整验收完成。以上一轮已推送的 `b4e10a0` 为基线。

Android 聊天、验证详情、任务通知与桌面两个助手入口采用同一验证协议，分开展示构建、单测、APK 和安装。结果必须来自本次实际执行的记录，包含任务身份、执行身份和时间；输入关联单独显示。零测试、全跳过、取消、未知和旧记录不标成通过。单测先于构建执行时仍保留证据，不能因为命令顺序丢失事实。

工作区输入摘要从原先部分审查路径扩展为根 Gradle 配置、wrapper、多模块源码和资源；排除生成目录，遇到符号链接、读取异常、并发变化及上限返回未知。摘要不证明外部依赖或实时工作区版本，详情见 [任务验证记录](VERIFICATION.md)。JUnit 只统计同一次命令新产生或变化的相同 variant 报告，并校验数量语义；任务列表读取持久化摘要，不扫描文件。

首轮端到端验收发现直接取消 Gradle 时，进程负退出码可能早于取消监听线程，从而把已取消记录为普通失败；现以持久化取消请求补充确认。新增端到端场景直接停止真实测试进程验证该竞态，保留失败记录作为修复依据。

交叉审查补齐结果与摘要的持久化顺序：最小验证记录先于规范工具结果写入，后续日志与问题详情只丰富同一次执行；可选详情读取失败不会让旧成功记录冒充最新执行。服务恢复会修补旧版已记录结果但缺验证摘要的窗口，并覆盖写入之间再次崩溃和重试的幂等行为。另修复 Anthropic 取消事件丢失 Gradle 任务参数的问题，保持事务写入时的敏感值脱敏。双端共享 API 示例同步加入实际解析断言。

最终默认发布门禁 **22/22 全通过，无跳过项**，报告 `.artifacts/iteration-003/release.json`：后端 **625 项测试、54 项子测试**；完整 HTTP/WebSocket E2E **29/29**；Android **206 项 JVM 测试**、Debug 构建和 lint（0 错误、345 条警告）；桌面单元、真实 Chromium 双入口、六种实际进程/JUnit 结果的 Electron 验证及原有 smoke、截图、创意接口全部通过，npm audit 为 0 漏洞。Android 模拟器另完成 **11 项设备验收**，含七种展示状态、同任务详情绑定、分项时间与耗时及临时配置清理，报告 `.artifacts/iteration-003/android-results.json`。首次门禁中共享契约校验值未同步而失败的记录保留为 `release-initial.json`；修复后的完整门禁重新执行，未以专项替代。

## 引导与追问回执

日期：2026-10-10。状态：实现、交叉审查和完整验收完成。以上一轮已推送的 `e827f86` 为基线。

本轮目标是让发送后的引导与追问可追踪、可对账、可安全重试。区分服务器保存消息、消息加入本轮上下文和后续任务创建，不将前两者描述成模型已采纳或工作已完成。首次发送生成稳定消息身份，丢失响应后的重试沿用相同身份与正文；两个有意发送的同文消息仍各自保留。

调研依据：[Codex 手机工作流](https://developers.openai.com/blog/mastering-codex-remote-for-engineering#2-learn-the-difference-between-queue-and-steer) 区分本轮引导和下一轮队列；[Cursor Agent](https://cursor.com/docs/agent/overview#queued-messages) 展示消息顺序并在工具边界接收引导；[Claude Code 交互说明](https://code.claude.com/docs/en/interactive-mode#queue-messages-while-claude-works) 显示尚未处理的输入，部分消息可在同轮工具完成后进入上下文。各平台的队列语义不同，本项目继续区分 `steer` 与 `follow_up`，借鉴可见回执和安全边界。

已确认的当前缺口：`include_consumed=true` 仍只返回待处理消息，响应缺少消费与后续任务身份；终态检查早于幂等查询，成功但丢失响应的请求可能在重试时被拒绝；追问创建与消费分别写入，重启或并发可能丢失调度或重复创建。双端还缺少稳定重试、迟到响应与新草稿的完整隔离，Android 任务运行时缺少可见的触摸发送入口。访客目前没有此接口权限，本轮保持 403，不扩大额度及授权范围。

采用保守的自动追问策略：父任务成功后按顺序创建后续任务；普通失败、取消或服务中断时保留可见阻塞回执，不自动执行。已经创建的后续任务关联永久保留。队列编辑、删除和重排不属于本轮。使用与协议见 [引导与追问回执](MESSAGE_RECEIPTS.md)。

交叉审查发现首个模型服务消费引导后发生故障时，备用服务会沿用旧历史快照，遗漏已确认消息。现切换前重读规范历史，同时恢复上下文与响应计数；新增双向 OpenAI/Anthropic、首次请求故障及完成工具后故障的四种回归，检查同文独立引导、原始提示和实际文件副作用均不丢失或重复。刷新范围限于初始历史和当前轮，运行期间后来排队的下一轮输入不会混入。发现此边界时终止了初次发布检查，保留日志并在定版后完整重跑。

最终默认发布门禁 **24/24 全通过，无跳过项**，报告 `.artifacts/iteration-004/release.json`：后端 **644 项测试、68 项子测试**；完整 HTTP/WebSocket E2E **34/34**；Android **229 项 JVM 测试**、Debug 构建和 lint（0 错误、347 条警告）；桌面单元、Chromium 双入口回执与旧功能回归、真实 Electron 消息/恢复/验证及原有 smoke、截图、创意接口全部通过，npm audit 为 0 漏洞。共享 API 回执样例由两端实际解析测试覆盖，Android 资源副本与契约校验值一致。

Android 模拟器另完成 **14 项设备验收**，覆盖发送与停止、回执状态、查看暂停子任务但不自动继续、脱敏失响应后重开并使用原标识重试、后台停止查询、返回刷新及迟到确认保护新草稿；报告 `.artifacts/iteration-004/android-results.json`。设备脚本核验预期检查集完整才报告通过，合成账号配置、数据库、服务和端口映射已清理。既有历史翻页测试的 Main 线程竞态也已修正，保留原断言和超时条件。两处桌面回执截图已目视验收，证据保存于同一忽略目录。
